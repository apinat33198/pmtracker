Import and export

Set up many sites at once from a spreadsheet. Each row is one PM task: a system at a site and its vendor. Missing sites, systems and vendors are created; existing tasks get their cycle updated; a last PM date is recorded if it's newer than what's on record.

Columns

site_code, system and vendor are required. Optional: site_name, region, interval_months, last_pm_date, anchor_mode (rolling or fixed), anchor_date, notes. Dates can be 2026-09-14, 14/09/2026 or 14/09/2569.

Export

The current status of every task, with last PM and next due dates. Its first columns match the import format, so you can edit it in a spreadsheet and import it back.
