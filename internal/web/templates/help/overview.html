หน้าแรกของแอป (Overview) แสดง PM ของทุก site ในหน้าเดียว เปิดหน้านี้ทุกเช้าแล้วไล่ดูของที่เป็นสีแดงและสีเหลืองก่อน

ตัวเลขตามสถานะ

แถวบนสุดคือจำนวน task ในแต่ละสถานะ (Overdue, Due soon, not booked, Off-cycle, No history, Booked, On track) กดที่ตัวเลขเพื่อกรองตาราง: ช่องที่ไม่ใช่สถานะนั้นจะจางลง กดซ้ำหรือกด Clear filters เพื่อดูทั้งหมด ความหมายของแต่ละสถานะอยู่ที่ สถานะและการคำนวณรอบ PM

ตัวกรอง

เลือก Region, System หรือ Vendor แล้วกด Apply ตัวกรองทำงานร่วมกับตัวเลขสถานะได้ เช่น ดูเฉพาะ CRAC ที่ Overdue ในภาคเหนือ ลิงก์ของหน้าเก็บตัวกรองไว้ จึงส่งลิงก์ให้คนอื่นเปิดเห็นแบบเดียวกันได้

ตาราง site × system

  • แถวคือ site จัดกลุ่มตามภูมิภาค จุดสีหน้ารหัส site คือสถานะที่เร่งที่สุดของ site นั้น กดชื่อ site เพื่อเปิดหน้า site
  • Last PM คือ PM ครั้งล่าสุดของ site (ระบบไหนก็ได้) และผ่านมากี่วันแล้ว
  • คอลัมน์คือ system ช่องแต่ละช่องคือ PM ครั้งถัดไปของ system นั้นที่ site นั้น
  • ในช่องแสดงวันนัดถ้ามีนัดแล้ว ไม่อย่างนั้นแสดงวันครบกำหนด พร้อมข้อความสั้น เช่น in 23d (อีก 23 วัน), 11d late (เลยมา 11 วัน), Booked หรือ Booked, off-cycle
  • สีของช่องคือสถานะของ task กดช่องเพื่อเปิดหน้า task เอาเมาส์ชี้เพื่อดูชื่อ vendor และวันที่เต็ม
  • ช่องที่มีสองรายการ (เช่น UPS ที่ BKK2) คือมีสอง vendor ทำ system เดียวกันที่ site นั้น แต่ละรายการบอกชื่อ vendor ไว้
  • ขีด — แปลว่า site นั้นไม่มี task ของ system นั้น

ถ้ามีแถบสีเหลืองว่า “past visits are waiting for someone to confirm it happened” แปลว่ามี visit ที่วันนัดผ่านไปแล้วแต่ยังไม่มีคนยืนยัน ระบบนับว่าทำแล้วไว้ก่อน เปิดหน้า site เพื่อกด Confirm done หรือ Mark missed (วิธียืนยัน)

Overdue and the next 30 days

รายการใต้ตาราง เรียงตามวันที่ต้องทำอะไรสักอย่าง (วันนัดถ้ามี ไม่อย่างนั้นวันครบกำหนด) มีทุก task ที่ Overdue และทุก task ที่ครบกำหนดหรือมีนัดภายใน 30 วัน ใช้เป็นรายการโทรตาม vendor ประจำสัปดาห์ได้

By vendor

สรุปต่อ vendor: ดูแลกี่ site กี่ task และมีกี่ task ที่ Overdue, Due soon หรือ Off-cycle กดชื่อ vendor เพื่อกรองตารางเหลือเฉพาะงานของ vendor นั้น มีเบอร์โทรให้กดโทรจากมือถือได้

Ad-hoc jobs

ถ้ามีงานครั้งเดียวที่ยังเปิดอยู่ จะแสดงท้ายหน้า (สูงสุด 8 รายการ) กด All jobs เพื่อดูทั้งหมด ดู Ad-hoc jobs

Export CSV

ปุ่ม Export CSV มุมขวาบนดาวน์โหลดสถานะของทุก task พร้อม PM ล่าสุดและวันครบกำหนด เปิดใน Excel ได้ภาษาไทยไม่เพี้ยน คอลัมน์แรก ๆ ตรงกับรูปแบบไฟล์ import แก้ใน spreadsheet แล้ว import กลับได้ (Import และ export)

กิจวัตรที่แนะนำ

  1. ทุกเช้า: ดูตัวเลข Overdue และ Due soon ตามงานกับ vendor ดู Review inbox ถ้ามีตัวเลข
  2. หลังวันนัด: ยืนยัน visit ที่หน้า site ภายในไม่กี่วัน หรือ Mark missed ถ้า vendor ไม่มา
  3. ทุกสัปดาห์: ดู Off-cycle แล้วขอให้ vendor เลื่อนนัดเข้าช่วงจอง
  4. ทุกเดือน: ดูหน้า Findings และ Incidents ว่ามีอะไรค้างหรือเกิดซ้ำ
