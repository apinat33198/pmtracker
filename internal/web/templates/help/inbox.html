vendor แต่ละรายตั้งชื่อนัดไม่เหมือนกัน บางรายใส่รหัส site บางรายใส่ชื่อภาษาไทย บางรายไม่ใส่ระบบ ระบบจับคู่นัดส่วนใหญ่ได้เอง ส่วนที่ไม่แน่ใจจะมารอใน Review inbox ให้คนตัดสินครั้งเดียว และบันทึกเป็นกฎไว้ใช้กับนัดครั้งต่อไปได้

ทำไม event มาอยู่ใน inbox

event จะมาที่ inbox เมื่อดูเหมือน PM แต่ผูกกับ task ที่แน่นอนไม่ได้ เช่น:

  • รู้ว่าเป็น PM แต่หา site ไม่เจอ (Site not recognised) เช่น รหัสใหม่ที่ยังไม่มีในระบบ หรือชื่อเรียก site ที่ยังไม่ได้ใส่เป็นชื่ออื่น (other names) ของ site
  • site นั้นมีสอง vendor ทำ system เดียวกัน และนัดไม่บอกว่า vendor ไหน (More than one vendor services this system here; pick one)
  • นัดไม่บอก system และ site มีหลาย task (No system or vendor in the event; several tasks at this site fit)
  • site ยังไม่มี task ของ system นั้น

แต่ละรายการแสดงวันที่ ชื่อนัด ปฏิทิน ผู้จัด สถานที่ ผู้ร่วมนัด และเหตุผล: ✓ คือสิ่งที่ระบบรู้แล้ว ✗ คือสิ่งที่ขาด นัดที่เกิดซ้ำ (recurring) แสดงครั้งที่ใกล้วันนี้ที่สุดครั้งเดียว พร้อมบอกว่ามีอีกกี่ครั้ง

ตัดสิน event editor

  1. เลือก task ใน Likely tasks (ถ้ามีตัวเลือกเดียวจะติ๊กไว้ให้แล้ว) หรือเลือกจาก Or another task ซึ่งแสดงทุก task จัดกลุ่มตาม site
  2. เลือก Apply to:
    • This event only: เฉพาะนัดนี้
    • Every event in this recurring series: ทุกครั้งของนัดที่เกิดซ้ำ (เลือกไว้ให้ถ้าเป็นนัดซ้ำ) เหมาะกับ vendor ที่ลงนัดรายไตรมาสไว้ล่วงหน้า
    • Every event titled “…”: ทุกนัดที่ชื่อตรงกันทุกตัวอักษร
  3. กด Link visit นัดกลายเป็น visit ของ task ที่เลือกทันที ถ้าเลือกเป็นกฎ นัดอื่นที่ตรงกฎก็ถูกจับคู่ไปด้วย

ถ้าไม่ใช่ PM (เช่น vendor มาเสนอขาย) กด Not a PM visit นัดจะออกจาก inbox และไม่ถูกนับ

ถ้า site ที่ต้องการไม่มีในรายการ admin เพิ่ม site ใหม่ หรือเพิ่มรหัสในชื่อนัดเป็น Other names ของ site เดิม แล้วนัดจะจับคู่ได้เองในการ sync ครั้งถัดไป{{if .IsAdmin}} (วิธีเพิ่มชื่ออื่นของ site){{end}}

กฎที่ระบบจำไว้

ทุกครั้งที่เลือก series หรือ title ระบบสร้าง learned rule ซึ่งใช้ก่อนการจับคู่แบบอื่นทั้งหมด admin ดูและลบกฎได้ที่ Calendars and sync ใต้หัวข้อ Learned rules การตัดสินแบบ This event only ไม่สร้างกฎ

หน้า Events

Events แสดงทุก event ที่อ่านจากปฏิทินที่ติดตาม พร้อมผลการจับคู่และเหตุผล ใช้ตรวจว่าทำไมนัดหนึ่งถึงไม่ขึ้น หรือขึ้นผิด task:

  • กรองด้วยปุ่มด้านบน: All, PM visits (จับคู่แล้ว), Needs review (อยู่ใน inbox), Not PM
  • คอลัมน์ Result: PM visit พร้อม task ที่ผูก, Needs review, Not PM หรือ Not PM, by hand
  • คอลัมน์ Why: เหตุผลแบบเดียวกับใน inbox
  • นัดที่ถูกยกเลิกจะมีขีดฆ่า
  • event ที่ตัดสินด้วยมือมีปุ่ม Undo decision editor เพื่อยกเลิกการตัดสิน event จะกลับไปให้ระบบจับคู่ใหม่ (และอาจกลับเข้า inbox)
