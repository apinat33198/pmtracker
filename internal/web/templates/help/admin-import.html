วิธีที่เร็วที่สุดในการตั้งทุก site คือกรอก spreadsheet แล้ว import ที่ Admin › Import and export หนึ่งแถวคือหนึ่ง PM task (system หนึ่งที่ site หนึ่ง กับ vendor ของมัน)

คอลัมน์

คอลัมน์จำเป็นความหมาย
site_codeใช่รหัส site เช่น BKK1
systemใช่ชื่อ system หรือชื่ออื่นของมัน (UPS, CRAC, DC power …)
vendorใช่ชื่อ vendor หรือชื่ออื่นของมัน
site_name, regionไม่ใช้ตอนสร้าง site ใหม่
interval_monthsไม่รอบ PM เป็นเดือน (ค่าเริ่มต้น {{.Cfg.Defaults.IntervalMonths}})
last_pm_dateไม่วัน PM ล่าสุด บันทึกเมื่อใหม่กว่าที่มีอยู่
anchor_modeไม่rolling (นับจาก PM ล่าสุด) หรือ fixed (วันตามสัญญา)
anchor_dateไม่First slot date (จำเป็นสำหรับ fixed)
notesไม่หมายเหตุของ task

นำเข้า

  1. เลือกไฟล์ CSV ที่ CSV file หรือวางแถวลงใน Or paste rows (บันทึกจาก Excel เป็น CSV UTF-8)
  2. กด Check without saving ระบบแสดงสิ่งที่จะเกิด: site, system, vendor และ task ใหม่กี่รายการ task ที่ถูกอัปเดต วัน PM ล่าสุดที่จะบันทึก และปัญหาแยกตามบรรทัด
  3. แก้ไฟล์จนไม่มีปัญหา แล้วกด Import
  • site, system และ vendor ที่ยังไม่มีจะถูกสร้างให้
  • task ที่มีอยู่แล้วจะถูกอัปเดตรอบ PM
  • วัน PM ล่าสุดจะบันทึกเมื่อใหม่กว่าที่มีในระบบเท่านั้น
  • ทั้งหมดหรือไม่มีเลย: ถ้ามีบรรทัดไหนมีปัญหา จะไม่บันทึกอะไรเลย
  • หลัง import ให้เติม email domain ของ vendor ใหม่ที่ Vendors

Export แล้วนำกลับ

Export status CSV ดาวน์โหลดสถานะของทุก task คอลัมน์แรก ๆ ตรงกับรูปแบบ import จึงแก้ใน spreadsheet (เช่น เปลี่ยนรอบ PM หลายรายการ) แล้ว import กลับได้
