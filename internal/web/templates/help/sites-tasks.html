กดชื่อ site ในหน้า Overview เพื่อเปิดหน้า site และกดช่องในตารางเพื่อเปิดหน้า task ของ system นั้น สองหน้านี้มีประวัติและรายละเอียดทั้งหมด

หน้า site

  • หัวหน้า: รหัส ชื่อ ภูมิภาค จำนวน task และ PM ครั้งล่าสุดของ site กล่องด้านขวาบอกสถานะที่เร่งที่สุดและจำนวน task ในแต่ละสถานะ
  • ตาราง task: หนึ่งแถวต่อหนึ่ง task มี Status, System (กับ vendor และรอบ), Last PM, Next due และ Booked (บอกว่านัดห่างจากวันครบกำหนดกี่วัน) กดชื่อ system เพื่อเปิดหน้า task
  • Timeline: แถบเล็กท้ายแถวแสดงช่วงเวลารอบวันนี้ ความหมายของสัญลักษณ์อยู่ที่ Timeline ด้านล่าง
  • Vendors at this site: ผู้ติดต่อ เบอร์โทร และอีเมลของทุก vendor ที่ site นี้ กดเบอร์เพื่อโทรจากมือถือได้
  • Findings และ Incidents: รายการที่ยังเปิดอยู่ของ site นี้ มีลิงก์ไปดูทั้งหมด (Findings, Incidents)
  • Ad-hoc jobs: งานครั้งเดียวที่ site นี้ พร้อมฟอร์มเพิ่มงาน (Ad-hoc jobs)
  • Record a PM visit editor: บันทึก visit ที่ไม่อยู่ในปฏิทิน ติ๊กได้หลาย system ถ้า vendor ทำหลายระบบในครั้งเดียว ดู บันทึก visit เอง
  • Recent visits: visit ล่าสุด 40 ครั้งของทุก task ที่ site นี้ พร้อมปุ่มยืนยัน (ยืนยันและบันทึก visit)

หน้า task

บรรทัดใต้ชื่อบอก vendor และช่องทางติดต่อ กล่องด้านขวาบอกสถานะและสิ่งที่ควรทำ (ข้อความภาษาอังกฤษจากระบบ) จากนั้นเป็นตัวเลขห้าช่อง:

ช่องความหมาย
Last PMPM ครั้งล่าสุดที่นับว่าทำแล้ว และสถานะของ visit นั้น (Done หรือ Done, unconfirmed)
Next dueวันครบกำหนดครั้งถัดไป และอีกกี่วัน (หรือเลยมากี่วัน)
Booking windowช่วงที่นัดแล้วนับว่าตรงรอบ คือวันครบกำหนด ± จำนวนวันของ task
Bookedวันนัดครั้งถัดไป และห่างจากวันครบกำหนดกี่วัน
Cycleรอบ PM และวิธีนับ: Counted from the last visit หรือ Fixed contract slots from …

ถ้าวันครบกำหนดตรงกับวันหยุด จะมีแถบเหลืองแนะนำวันทำงานที่ใกล้ที่สุดให้เสนอ vendor ใต้ timeline มีรายการ findings และ incidents ของ system นี้ visit ทั้งหมด และฟอร์ม Record a past visit สำหรับประวัติจากเอกสารกระดาษ

Timeline

หน้า task มี timeline ใหญ่ 12 เดือนย้อนหลังและ 12 เดือนข้างหน้า หน้า site มีแบบย่อ เอาเมาส์ชี้สัญลักษณ์เพื่อดูวันที่:

  • จุดทึบ: visit ที่ทำแล้ว
  • เส้นประแนวตั้ง: วันนี้
  • แถบสี: ช่วงจอง และรูปข้าวหลามตัดในแถบคือวันครบกำหนด
  • วงกลมโปร่ง: visit ที่นัดไว้
  • วงกลมเส้นประ: วันครบกำหนดที่คาดไว้อีกสามรอบข้างหน้า (บรรทัดใต้ timeline บอกวันที่ไว้ด้วย)
