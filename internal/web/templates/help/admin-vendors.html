รายชื่อ vendor และ system เป็นข้อมูลกลางที่ทุกฟอร์มใช้ ข้อมูลที่ครบช่วยให้นัดในปฏิทินจับคู่ได้เองมากขึ้น และทีมโทรหา vendor ได้จากหน้า site ทันที

ข้อมูล vendor

ที่ Admin › Vendors กด Add a vendor หรือ Edit:

ช่องใช้ทำอะไร
Nameชื่อที่แสดงทุกที่ในแอป
Contact person, Phone, Emailแสดงในหน้า site, หน้า task และ By vendor กดโทรหรืออีเมลได้
Email domainsนัดที่ผู้จัดหรือผู้ร่วมนัดใช้อีเมลโดเมนนี้จะถูกผูกกับ vendor นี้ สำคัญที่สุดสำหรับการจับคู่ ใส่อีเมลแล้วระบบเพิ่มโดเมนให้เอง ยกเว้นโดเมนอีเมลทั่วไปอย่าง gmail.com
Other names in event titlesชื่อย่อหรือชื่อเรียกที่ vendor ใช้ในชื่อนัด คั่นด้วยจุลภาค เช่น VoltEdge
Notesเลขสัญญา เวลาทำการ ฯลฯ

หน้ารายการแสดงว่าแต่ละ vendor ดูแล system อะไรที่ site ไหน และมีกี่ task ที่ต้องตาม (overdue, due soon, off-cycle) หน้า vendor แสดงทุก task ของ vendor นั้น

ย้าย task ไป vendor อื่น

เมื่อสัญญาเปลี่ยนผู้รับจ้าง: เปิดหน้า vendor เดิม ที่ Change vendor or delete เลือก vendor ใหม่ใน Move tasks to ติ๊ก Then delete … ถ้าจะลบ vendor เดิมด้วย แล้วกด Move tasks ทุก task ย้ายไปพร้อมประวัติ visit เดิม

ลบ vendor

ลบได้เมื่อไม่มี PM task เหลือแล้ว ย้ายหรือลบ task ก่อน visit ในอดีตไม่ได้รับผลกระทบ

Systems

Admin › Systems คือชนิดอุปกรณ์ที่ทำ PM แต่ละ system เป็นหนึ่งคอลัมน์ในหน้า Overview (แสดงเฉพาะ system ที่มี task)

  • Name: ชื่อที่แสดง
  • Other names in titles: คำที่ระบบหาในชื่อนัดเพื่อรู้ว่าเป็น system นี้ เช่น CRAC อาจมี PAC, Precision AC, แอร์
  • ลบ system ได้เมื่อไม่มี task ใช้อยู่

ตั้งชื่ออื่นให้เฉพาะเจาะจง คำสั้นอย่าง DC อาจหมายถึง “data centre” ในชื่อนัดได้ด้วย ทำให้ระบบจับคู่ผิด ฟอร์มเพิ่ม task มีช่องค้นหา system: พิมพ์ชื่อหรือชื่ออื่น (เช่น PAC จะเจอ CRAC) ถ้าพิมพ์ชื่อที่ตรงกับ system เดิม ระบบใช้ system เดิมเสมอ จึงไม่เกิดคอลัมน์ซ้ำ
